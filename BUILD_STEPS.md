# FinalForge — Build Roadmap

## V1 — Foundation ✅
Responsive four-module study hub, exam schedule, lesson tracking, planner and resource library structure.

## V2 — Practice ✅
Quizzes, explanations, readiness scoring, Java practice, structured/essay practice and referral-sheet builder.

## V3 — Experience ✅
3D UI, motion/transitions, Mock Paper Studio, autosave/resume, weak-topic analytics and printable papers.

## V4 — Secure Access ✅ code complete
Approved Student-ID allowlist, mobile OTP registration, Student ID + password login, recovery flow, admin role and cloud progress architecture.

## V5 — FinalForge Launch Candidate ✅ current
FinalForge rebrand, public/private separation, compact production bundle, PWA assets, security headers, printable mock-pack bundle and GitHub launch source.

## V5.1 — Firebase activation ⏭
Create/configure Firebase, enable Phone + Email/Password auth, deploy rules, privately seed the roster and provision the admin custom claim.

## V5.2 — Resource binary hosting ⏭
Publish the lecture/tutorial/lab/practical PDFs without exposing the private roster. The source repository currently contains the resource metadata but not the ~115 MB course-file payload.

## V5.3 — Production deployment ⏭
Import `teldigi5-wq/finalforge` into Vercel, deploy, add the live domain to Firebase Authorized Domains and run production smoke tests.

## V5.4 — Device QA ⏭
Android Chrome/PWA, iPhone Safari, tablet, laptop/desktop, keyboard accessibility, performance and offline-cache tests.

## V6 — Smart Learning 🔜
Mid-exam mode, announcements, bookmarks, adaptive practice, richer weak-topic analytics, personalized study plans and future-semester content.
